This folder contains several scripts which re-create figures from the paper and other visualizations. These visualizations use results from processed videos, available in our released dataset (see main README for download information). More scripts and information will be added soon

## Contents

- `condensed_results.ipynb`: Includes aggregate results from all videos plotted together to show spatial patterns. 
- `mandible_direction_comp.ipynb`: Compares strikes performed with different mandible orders. 
- `temporal_response.ipynb`: Plots displacement, velocity, acceleration, and jerk profiles for various regions of the ant gena.
